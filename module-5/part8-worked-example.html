A Fully Worked Multilevel Modeling Example

A student brings us a result: transparent fee disclosure appears to increase adoption intent. The p-value is small. The plot looks clean. But before we believe the estimate, we audit the data. We find seven threats: repeated observations, sampled stimuli, treatment-risk imbalance, nonlinear product valuation and fatigue, differential missingness, post-treatment exclusion risk, and treatment-effect heterogeneity.

The rest of this chapter shows how to diagnose where each threat comes from, which statistical adjustment reduces it, and what remains when the chapter ends.

The key framing: Statistical fixes minimize threats — they do not erase them. The goal is not to find an analysis that says everything was fine. It is to show exactly what each adjustment addressed, what it could not address, and what the final claim depends on.

1. The Research Question and Estimand

Does transparent fee disclosure increase willingness to adopt a financial product, and does that effect generalize across participants, product offers, and research sites?

The target estimand is the average total effect of assigned fee transparency on willingness to adopt, averaged over the population of participants, product offers, and research contexts similar to those sampled. This is an intention-to-treat estimand: the effect of the display assignment, not the effect of comprehension or perceived clarity.

This question contains several distinct questions a naive regression cannot answer:

  • Effect for these participants (descriptive)
  • Effect across the population of participants (requires participant random effects)
  • Effect across the population of product offers (requires stimulus random effects)
  • Effect across different sites (requires site random effects)
  • Effect conditional on financial literacy (requires the interaction)

3. Simulate the Latent DGP

The true data-generating process is known. But the realized data will not look like it, for three reasons: (1) the fee-transparency display was more often served to high-risk products in later trials and at site 2 — a real implementation pattern mimicking a platform rollout; (2) trial-order fatigue is real and non-trivial; (3) the observation process introduces non-random missingness and attention failures.

Code 
dgp <- list(
  intercept           = 50,
  effect_transparency = 4,      # +4 at average literacy — the true target
  effect_risk         = -2.0,   # linear risk penalty
  effect_risk_high    = -2.5,   # extra threshold penalty for risk > 0.75
  effect_ev_linear    = 2.2,    # EV (standardised), linear
  effect_ev_quad      = -1.0,   # diminishing returns on EV
  effect_literacy     = 2,
  interaction_tx_lit  = -1.5,   # transparency helps low-literacy more
  effect_fatigue      = -0.18,  # per trial
  effect_fatigue_late = -1.20,  # additional penalty for trials 10–12
  effect_device       = -1.5,   # mobile device: lower ratings
  sd_participant      = 8,
  sd_stimulus         = 5,
  sd_site             = 4,
  sd_slope_part       = 2,
  sd_residual         = 7
)
Code 
n_participants  <- 240
n_stimuli       <- 36
n_sites         <- 4
trials_per_part <- 12

participants <- tibble(
  participant_id     = 1:n_participants,
  site_id            = rep(1:n_sites, each = n_participants / n_sites),
  financial_literacy = rnorm(n_participants, 0, 1),
  u0_participant     = rnorm(n_participants, 0, dgp$sd_participant),
  u1_participant     = rnorm(n_participants, 0, dgp$sd_slope_part)
)

site_effects <- tibble(
  site_id = 1:n_sites,
  u0_site = c(3, -2, 1, -2)
)

stimuli <- tibble(
  stimulus_id    = 1:n_stimuli,
  risk_level     = rnorm(n_stimuli, 0, 1),
  expected_value = rnorm(n_stimuli, 50, 15),
  u0_stimulus    = rnorm(n_stimuli, 0, dgp$sd_stimulus)
) |>
  mutate(
    expected_value_z = (expected_value - 50) / 15,
    risk_high        = as.integer(risk_level > 0.75)
  )

trials <- participants |>
  select(participant_id, site_id, financial_literacy, u0_participant, u1_participant) |>
  cross_join(tibble(draw = 1:trials_per_part)) |>
  group_by(participant_id) |>
  mutate(
    stimulus_id   = sample(1:n_stimuli, trials_per_part, replace = FALSE),
    trial_order   = 1:trials_per_part
  ) |>
  ungroup() |>
  select(-draw) |>
  left_join(stimuli, by = "stimulus_id") |>
  left_join(site_effects, by = "site_id") |>
  mutate(
    # Device: more common at sites 2–3 (online platforms)
    device_mobile = rbinom(n(), 1, plogis(-0.3 + 0.6 * as.integer(site_id %in% c(2, 3)))),

    # IMPERFECT ASSIGNMENT: transparency correlated with risk, trial order, and site 2
    # This mimics a platform that served the transparent display more often for
    # high-risk products and in later trials — a realistic implementation artefact
    trial_order_z = (trial_order - 6.5) / 3.452,
    p_tx = plogis(0.70 * risk_level + 0.40 * trial_order_z + 0.50 * as.integer(site_id == 2)),
    transparency  = rbinom(n(), 1, p_tx),

    # Latent mean (true DGP — clean causal structure)
    mu = dgp$intercept +
         dgp$effect_transparency  * transparency +
         dgp$effect_risk          * risk_level +
         dgp$effect_risk_high     * risk_high +
         dgp$effect_ev_linear     * expected_value_z +
         dgp$effect_ev_quad       * expected_value_z^2 +
         dgp$effect_literacy      * financial_literacy +
         dgp$interaction_tx_lit   * transparency * financial_literacy +
         dgp$effect_fatigue       * trial_order +
         dgp$effect_fatigue_late  * as.integer(trial_order > 9) +
         dgp$effect_device        * device_mobile +
         u0_participant + u1_participant * transparency +
         u0_stimulus + u0_site,

    # Heteroskedastic residuals: more variance for high-risk products and
    # low-literacy participants
    resid_sd = dgp$sd_residual * exp(
      0.25 * abs(risk_level) +
      0.20 * as.integer(financial_literacy < -1)
    ),
    adoption_intent = pmin(100, pmax(0, rnorm(n(), mu, resid_sd)))
  ) |>
  select(participant_id, site_id, stimulus_id, trial_order,
         transparency, risk_level, risk_high, expected_value, expected_value_z,
         financial_literacy, device_mobile, adoption_intent)

4. The Observation Process

A real experiment does not deliver adoption_intent for every trial. Between the latent DGP and the analyst’s dataset:

  • Some trials are missing because participants quit, skip, or time out.
  • Missingness depends on the treatment (transparent displays require more effort), risk level, trial position, literacy, and device.
  • Some trials produce attention-check failures — and those failures are partly caused by the treatment.
Code 
set.seed(20240611)

trials <- trials |>
  mutate(
    # Missingness: related to treatment, risk, trial fatigue, literacy, device
    p_missing = plogis(
      -2.5 +
        0.45 * transparency +
        0.55 * risk_level +
        0.45 * as.integer(trial_order > 9) -
        0.50 * financial_literacy +
        0.35 * device_mobile
    ),
    missing_y           = rbinom(n(), 1, p_missing),
    adoption_intent_obs = if_else(missing_y == 1, NA_real_, adoption_intent),

    # Attention failures: more common under transparent displays, late trials,
    # and for low-literacy participants — a post-treatment process variable
    attention_fail = rbinom(n(), 1,
      plogis(-3.0 +
             0.50 * transparency +
             0.35 * risk_level +
             0.45 * as.integer(trial_order > 9) -
             0.40 * financial_literacy))
  ) |>
  select(-p_missing)

5. Initial Inference Threat Dashboard

ImportantWe Are Starting With 7 Open Threats

Before fitting a single model, we inventory the inference problems visible in the data. These are not hypothetical — we can see each one in tables and plots.

  1. Participant dependence — same participants appear in multiple rows.
  2. Stimulus generalization — product-level attractiveness dominates responses; stimuli are sampled, not exhaustive.
  3. Treatment-risk imbalance — transparent trials disproportionately involve high-risk products and later trial positions.
  4. Nonlinear product valuation and fatigue — risk and EV have threshold/diminishing effects; late-trial fatigue is non-trivial.
  5. Differential missingness — missing outcomes are more common for transparent, high-risk, late-trial, low-literacy, and mobile trials.
  6. Post-treatment exclusion risk — attention failures are partially caused by the treatment; excluding them narrows the sample in a non-neutral way.
  7. Treatment-effect heterogeneity — the transparency effect varies across participants and by financial literacy.

Each section below addresses one or more of these. We keep a running count.

21. What We Fixed vs What We Did Not Fix

What the analysis substantially reduced

  • Row dependence — participant and stimulus random intercepts correctly separate within-person/within-product estimates from between-unit baselines.
  • Treatment-risk imbalance — adding risk level (linear + threshold) removed the largest source of bias. The naive estimate was ~2.2 points too low.
  • Nonlinear product valuation — the quadratic EV term and risk_high indicator removed residual misfit from functional-form assumptions.
  • Trial-order fatigue — adding trial_order as a fixed effect removed the downward confounding from transparent trials occurring later in the task.
  • Observed differential missingness — adding device_mobile adjusted for one source of differential dropout.
  • Post-treatment exclusion ambiguity — we reported both the intent-to-treat and the attention-excluded estimates and described the estimand difference.

What the analysis did not fully solve

  • MNAR — if participants with low latent adoption intent are disproportionately the ones skipping transparent high-risk late-trial observations, no covariate adjustment addresses it. The sensitivity test is informative but not conclusive.
  • Post-treatment selection — excluding attention failures restricts the sample to trials processed without difficulty. That restriction is not neutral, and the “correct” choice depends on the intended estimand, not on data quality alone.
  • Limited site generalization — with four sites, the site random intercept is estimated from very little information. Site heterogeneity in the transparency effect cannot be reliably detected at this design.
  • Heteroskedasticity — the LMM’s constant-variance assumption is violated for high-risk stimuli. For policy claims targeted at high-risk products, confidence intervals may be too narrow.
  • Unobserved product features — risk level and expected value capture some product characteristics, but other attractiveness dimensions (brand familiarity, temporal framing, product complexity) are absorbed into the stimulus random effect and may not be adequately controlled.

The honest final claim

After diagnosing and removing the main observed threats to inference — treatment-risk imbalance, fatigue confounding, nonlinear covariate effects, and partial missingness adjustment — fee transparency appears to increase adoption intent by approximately 3.8 points at average financial literacy (true DGP: 4). The effect is larger for lower-literacy participants. This estimate is meaningfully more credible than the naive result, but it still depends on assumptions about whether missingness is MAR conditional on observed covariates, whether attention exclusions are neutral for the estimand, and whether the four-site sample represents the intended population of deployment contexts.

22. What a Reviewer Would Ask

1. “The naive estimate was substantially below the true effect. Was the assignment actually randomized?”

No — not in this dataset. The assignment audit showed that the fee-transparency display was more commonly served to high-risk products, later trial positions, and participants at site 2. This is a known implementation pattern in platform-based studies where display logic interacts with product metadata. The bias was removed by covariate adjustment, but a reviewer is right to ask this question.

2. “Your main models are complete-case. How do you handle missing outcomes?”

Missingness is non-trivial (~16%) and differential: transparent trials have higher dropout. We documented this in the missingness audit and compared a complete-case model to one including the main missingness predictors. The shift was 0.019 points. The remaining concern is MNAR — if latent adoption intent predicts dropout over and above the observed covariates — which we cannot directly test.

3. “You excluded attention-check failures. That’s a post-treatment variable.”

We did not exclude them in the primary analysis. We ran both an all-observed estimate and an attention-excluded estimate and reported both. Attention failures were more common in the transparent condition, consistent with the display being more cognitively demanding. Excluding them increases the estimate, which is the expected direction if removed trials had lower adoption intent. We flag this as an estimand issue, not a data quality fix.

4. “Why is expected value quadratic? That seems arbitrary.”

Diminishing sensitivity to expected value is psychologically motivated: people are not linearly sensitive to financial value at all magnitudes. We confirmed this choice with a residual diagnostic — the loess curve over expected value showed visible nonlinearity after the linear adjustment. Forcing linearity leaves systematic residual misfit.

5. “Trial order is in your model. How do you know it’s a fatigue effect and not a learning effect?”

The residual plot after m4 shows that later trials have lower adoption intent on average, which is more consistent with fatigue than learning (learning would increase ratings over time). The fatigue interpretation is also supported by the DGP — but in a real dataset, we cannot distinguish cleanly. We would recommend noting this ambiguity and checking whether the trial-order effect differs by condition.

6. “The literacy interaction is theoretically motivated. Did you pre-register it?”

This worked example is a tutorial, not a report. In a real study, the interaction between financial literacy and fee transparency is a plausible and theoretically grounded moderation hypothesis. Pre-registration is the appropriate way to control family-wise error for exploratory moderation tests.

7. “Four sites is a small sample for a random effect.”

Correct. With four sites, the site random-effect variance is estimated from very few data points. The site RI is still the right specification — it correctly represents that sites are a sample from a population of contexts — but the variance estimate is unreliable. A sensitivity analysis treating site as fixed (using factor(site_id)) would show whether site-level differences substantially change the transparency estimate.

8. “What is the estimand?”

The average total effect of assigned fee transparency on willingness to adopt, averaged over the population of participants, product offers, and contexts similar to those sampled — at average financial literacy. The moderated effect at specific literacy levels is a secondary estimand. Comprehension and perceived transparency are excluded from the model because they are mechanisms, not confounders.

9. “Why does heteroskedasticity not concern you more?”

It concerns us, but not for the transparency point estimate. The transparency effect is a within-person contrast that is robust to mean-independent variance heterogeneity in most cases. Where it matters: confidence intervals for subgroup estimates in high-risk stimuli may be too narrow. We flag this as a caveat.

10. “Can you say the model ‘recovered’ the true effect?”

In this simulation we know the truth, so yes — we know the final estimate is close to the true effect. In a real dataset, we cannot verify recovery. What we can say is that the estimate is now more defensible: the major observed threats have been addressed, the modeling sequence has been documented, and the remaining assumptions have been stated explicitly.
