Time Structure, Fixed Effects, and Seasonal Cycles

NoteThe Time Structure Question

What happens when you ignore calendar time in a longitudinal analysis? Three things can go wrong simultaneously: a secular trend (the world is changing) inflates or deflates your treatment estimate; a seasonal cycle (spending is higher in December) creates false patterns correlated with when treatment was assigned; and period-specific shocks (a macro event in month 15) get absorbed into the wrong parameters.

How do you know time is a confounder? Residuals from your model should have zero mean at every time point. If the residuals trend upward, you have unmeasured trend. If the residuals oscillate with a 12-month period, you have unmeasured seasonality. Both are diagnosable from simple plots.

What is the fix? At minimum, include time as a predictor — as a linear trend, as Fourier terms for cyclical patterns, or as period fixed effects (dummy variables for every calendar period). The choice depends on how much parametric structure you are willing to assume about the time DGP.

One Dataset, Many Models

This section works differently from most of the module. Instead of showing several separate examples, we build one realistic longitudinal dataset and run it through five progressively better specifications. The true data-generating process is fully disclosed at the start. After each model you can see exactly how much bias remains and what diagnostic reveals it.

The setting is drawn from consumer finance. A fintech platform tracks monthly spending (£) for 120 app users over 24 months (January 2023 through December 2024). The platform introduced a voluntary Loyalty Program partway through, and the research question is: does program membership cause higher spending?

Three features of this DGP create realistic analytical challenges:

  1. A secular trend — platform adoption and mild inflation push spending up by £3 per month across all users, regardless of program status.
  2. A seasonal cycle — December spending is £60 above average (holiday purchases); June is £60 below. The cycle repeats every 12 months.
  3. Staggered, non-random enrollment — higher-spending users are more likely to join the program, and a November–December marketing push concentrates enrollment in the holiday season. Both features create confounding if not addressed.

Building the Dataset

The True Data-Generating Process

TipTrue DGP Parameters
Parameter Symbol True value
Loyalty program effect \(\beta_{\text{loyalty}}\) £35
Secular trend (per month) \(\beta_{\text{trend}}\) £3
Seasonal amplitude \(A\) £60
Between-person SD \(\sigma_u\) £80
Within-person residual SD \(\sigma_e\) £40
Person baseline mean \(\mu\) £500

\[ Y_{it} = \underbrace{\alpha_i}_{\text{person baseline}} + \underbrace{35 \cdot D_{it}}_{\text{loyalty effect}} + \underbrace{3 \cdot t}_{\text{trend}} + \underbrace{60 \cos\!\left(\tfrac{2\pi\, m_t}{12}\right)}_{\text{seasonal cycle}} + \underbrace{\varepsilon_{it}}_{\text{noise}} \]

where \(t\) is the calendar month (1–24), \(m_t\) is the month of year (1–12), and \(\varepsilon_{it} \sim \mathcal{N}(0, 40^2)\).

What each term does:

  • Each row is one user–month combination. There are \(120 \times 24 = 2{,}880\) rows.
  • \(\alpha_i \sim \mathcal{N}(500, 80^2)\) is the person-level baseline — their stable spending level if enrolled for a full year at the middle of the study window with no program.
  • The loyalty term is what we want to recover. The truth is £35: program members spend £35 more per month because of the program, not because they were already higher spenders.
  • The trend term adds £3 per calendar month to everyone — a rising tide. By month 24 the average user spends £72 more than in month 1 just from trend.
  • The seasonal term uses \(\cos(2\pi m_t / 12)\): it equals \(+1\) when \(m_t = 12\) (December, spending peak at \(\mu + 60\)) and \(-1\) when \(m_t = 6\) (June, trough at \(\mu - 60\)). The annual swing is £120.
Code 
set.seed(2025)

n_hh     <- 120
n_months <- 24

# ── True DGP parameters ───────────────────────────────────────────────────
true_loyalty   <- 35   # £/month causal program effect
true_trend     <- 3    # £/month secular increase
true_amplitude <- 60   # seasonal ±£60 (Dec peak, Jun trough)
true_person_sd <- 80   # between-person SD
true_resid_sd  <- 40   # within-person noise SD

# ── Person-level baselines ────────────────────────────────────────────────
person_baselines <- rnorm(n_hh, 500, true_person_sd)

# ── Staggered enrollment via discrete-time hazard ─────────────────────────
# Each non-enrolled user has a monthly probability of joining, which is:
#   (a) higher for users with higher baseline spending, and
#   (b) boosted in November (moy=11) and December (moy=12) by a marketing campaign.
# ~65% of users will eventually enroll; the rest never do.
enroll_month <- rep(NA_integer_, n_hh)
for (hh in seq_len(n_hh)) {
  for (m in 4:22) {
    moy <- ((m - 1L) %% 12L) + 1L
    p_base    <- 0.025                                        # 2.5% base monthly hazard
    p_person  <- max(0, (person_baselines[hh] - 500) / 80) * 0.025  # high spenders more likely
    p_holiday <- if (moy %in% c(11L, 12L)) 0.05 else 0      # holiday marketing boost
    p         <- min(p_base + p_person + p_holiday, 0.15)
    if (runif(1) < p) { enroll_month[hh] <- m; break }
  }
}

# ── Build the panel ────────────────────────────────────────────────────────
df <- expand_grid(person = seq_len(n_hh), month = seq_len(n_months)) |>
  mutate(
    month_of_year = ((month - 1L) %% 12L) + 1L,
    # Fourier basis for 12-month cycle
    cos_12 = cos(2 * pi * month_of_year / 12),
    sin_12 = sin(2 * pi * month_of_year / 12),
    # Treatment indicator: 1 once enrolled, 0 otherwise
    enroll_m = enroll_month[person],
    loyalty  = as.integer(!is.na(enroll_m) & month >= enroll_m),
    # True outcome components (exposed for diagnostics)
    person_component   = person_baselines[person],
    trend_component    = true_trend * month,
    seasonal_component = true_amplitude * cos_12,
    true_y = person_component + trend_component + seasonal_component +
             true_loyalty * loyalty,
    # Observed spending
    noise    = rnorm(n(), 0, true_resid_sd),
    spending = true_y + noise,
    person_f = factor(person)
  )

cat("Users enrolled by end of study:", sum(!is.na(enroll_month)),
    "/", n_hh, sprintf("(%.0f%%)\n", 100 * mean(!is.na(enroll_month))))
Users enrolled by end of study: 62 / 120 (52%)

Why Time Confounds Treatment Estimates

Before fitting any model, here is the confounding logic in plain language.

Person-level confound. Higher-spending users are more likely to enroll in the loyalty program. A naïve comparison (loyal users vs. not) conflates the program effect with the pre-existing spending advantage of the users who joined.

Trend confound. Enrollment is staggered: higher-spending users tend to enroll earlier (months 4–10); lower-spending users trickle in later. Because spending trends upward by £3/month for everyone, a person who enrolled in month 5 will have 19 months of post-enrollment data concentrated in the later, higher-spending part of the study window. Their within-person “before vs. after” comparison absorbs the secular trend as if it were a program effect.

Seasonal confound. The November–December marketing campaign means enrollment peaks during the highest-spending months of the year. The months immediately following enrollment are January–February — the lowest-spending months. If we ignore the seasonal cycle, the post-enrollment winter trough looks like a drag on the effect, or creates a timing-based artifact in any period-level comparison.

All three confounds are visible in residuals and diagnosable before you ever look at a parameter table.

The simplest possible analysis: regress spending on loyalty program membership, no other controls.

Reading the diagnostics:

  • Left plot (residuals vs. calendar month): The upward slope shows the secular trend that the naïve model did not capture. Residuals grow by roughly £3 per month on average — exactly the true trend.
  • Middle plot (residuals vs. month-of-year): The wave pattern shows the seasonal cycle. December residuals are around +£60; June residuals are around −£60. This is precisely the amplitude of the true seasonal DGP component.
  • Right plot (ACF): The spike at lag 12 is the fingerprint of a 12-month periodic structure. A significant autocorrelation at lag 12 in panel-mean residuals is the standard diagnostic for unmodeled annual seasonality.

Model 3: Fourier Terms for the Seasonal Cycle

A 12-month cycle can be fully described by one pair of Fourier terms: \(\cos(2\pi m / 12)\) and \(\sin(2\pi m / 12)\). These two terms together can capture any phase and amplitude for a pure annual cycle.

NoteWhy Fourier Terms?

A seasonal cycle with period \(P\) can be written as: \[f(t) = A \cos\!\left(\frac{2\pi t}{P}\right) + B \sin\!\left(\frac{2\pi t}{P}\right)\] This is equivalent to \(R \cos(2\pi t/P - \phi)\), where \(R = \sqrt{A^2 + B^2}\) is the amplitude and \(\phi = \arctan(B/A)\) is the phase. Including both the cosine and the sine as regressors lets the data determine both the amplitude and the peak month without you having to specify either.

In our DGP, the true cycle uses only cosine (\(B = 0\), peak in December), so the sine coefficient should be near zero in a correctly specified model.

Model 4: The Full Specification — Person Random Effects

Adding person random intercepts addresses the final confound. Now we are comparing each user’s spending during their enrolled months to their own spending during their non-enrolled months, after removing the shared trend and seasonal cycle.

Code 
m4 <- lmer(spending ~ loyalty + month + cos_12 + sin_12 + (1 | person_f), data = df)

tidy(m4, effects = "fixed") |>
  filter(term %in% c("loyalty", "month", "cos_12", "sin_12")) |>
  mutate(
    true_value = c(true_loyalty, true_trend, true_amplitude, 0),

Model 5: Period Fixed Effects (Month Dummies)

As a non-parametric benchmark, we can replace the trend + Fourier terms with a separate dummy variable for each calendar month. This month fixed effects approach makes no assumptions about the shape of the time trend or seasonal cycle — it absorbs all calendar-month variation, whatever its source.

Feature Model 4 (mixed + Fourier) Model 5 (two-way FE)
Time structure assumed Linear trend + 12-month cycle None
Degrees of freedom used for time 3 (month, cos_12, sin_12) 23 (one dummy per month)
Precision (SE) Higher (more efficient) Lower (spends df on dummies)
Extrapolation Possible (parametric) Not possible
Person effects Random (borrows strength) Fixed (no pooling)

The Fourier model wins on efficiency when the parametric assumption is correct. The period FE model wins on robustness when you are unsure whether the time structure is truly smooth and periodic.

Practical Guide: Which Diagnostic, When?

When you receive a new longitudinal dataset, run these diagnostics in order before specifying any model:

Five-step diagnostic sequence for longitudinal time structure
Step Diagnostic What you’re looking for Remedy
1 Plot mean outcome by calendar time Upward/downward slope → secular trend present Add time as a linear or polynomial predictor
2 Plot mean outcome by time-of-year / period-of-week Repeated wave pattern → seasonal cycle present Add Fourier sin/cos terms or period-of-year dummies
3 Fit a naïve model; plot mean residuals by calendar time Still trends after your controls → trend not captured Add a higher-order polynomial or period dummies
4 Plot mean residuals by time-of-year Still waves after your controls → seasonality not captured Add Fourier terms or seasonal dummies
5 Plot ACF of panel-mean residuals Spike at lag k → k-period autocorrelation remaining Model residual autocorrelation (AR structure, Module 4 Part 5)

WarningReviewer Challenge

What a skeptical reviewer would say: “You control for a linear time trend, but what if the trend is nonlinear? A quadratic trend or a structural break in month 12 would not be captured. Your loyalty estimate could absorb a nonlinear acceleration in spending that happened to coincide with program launch.”

Observable warning sign: Residuals vs. calendar month show a curve rather than a flat line even after including a linear trend term.

What claim survives: The direction of the loyalty effect is likely correct. The magnitude depends on how closely the parametric time model matches the true time structure. Period fixed effects (Model 5) provide a robustness check that does not impose any parametric shape on the time trend.

Setting the Stage for Growth Curve Models

Everything in this section treated time as a confounder — something to control so that the treatment estimate is unbiased. The next section, Growth Curve Models, treats time as the phenomenon of interest: how does each person’s trajectory unfold, and why do trajectories differ across people?

The diagnostic toolkit introduced here — residual-by-time plots, seasonal diagnostics, ACF checks — applies directly to growth curve models. When you move to random slopes and nonlinear trajectories, the same residual plots will tell you whether your trajectory model has adequately captured the time structure or whether a remaining confound is distorting the picture.
