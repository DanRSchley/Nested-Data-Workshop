Cross-Lagged Panel Models

NoteThe Cross-Lagged Question

What is the scientific question? CLPM and RI-CLPM are for questions about temporal ordering — does A at time t predict B at time t+1, after controlling for B’s own stability? They are not the right tool for questions about mean levels, trajectories, or causal effects from intervention.

What does this model assume about time? That the relationship between the two variables is stationary — the same cross-lagged structure holds across all waves. And that autoregressive effects accurately capture the persistence of each variable.

The fundamental problem with classic CLPM: Cross-lagged paths in the classic model mix within-person dynamics with between-person stable differences. People who are chronically financially stressed also tend to borrow more riskily — not because stress causes borrowing, but because both reflect the same underlying stable trait. The classic CLPM conflates these two stories.

Should You Use a CLPM at All?

Before fitting, assess whether CLPM is appropriate for your design and question.

WarningPre-Fit Decision: Is CLPM the Right Tool?

CLPM is likely not appropriate when:

Situation Problem Better alternative
Only 2 waves Cannot distinguish cross-lagged from concurrent correlation Collect a third wave; use change score analysis
Waves are widely or unequally spaced Lag coefficients are hard to interpret; stationarity assumption more questionable Use continuous-time models; report the lag interval
Strong stable between-person differences Cross-lagged paths will reflect trait differences, not within-person dynamics Use RI-CLPM to separate stable from dynamic components
Poor reliability of either variable Attenuation bias in cross-lagged paths; ME inflates residuals Model measurement error explicitly or use RI-CLPM
Variables have strong trends Non-stationarity violates the core assumption Detrend variables first; use growth model approach

CLPM is most trustworthy when you have 3+ equally spaced waves, the variables are relatively stable within-person (high autoregressive effects), and between-person trait differences are small relative to within-person fluctuation.

Two Variables, Evolving Together

Suppose you want to understand the relationship between financial stress and risky borrowing behavior over time. Does financial stress push people toward riskier borrowing? Or does risky borrowing create financial strain? Or do they mutually reinforce each other?

To answer this, you need data on both variables at multiple time points, and you need a model that can disentangle the temporal ordering of their relationship. The cross-lagged panel model (CLPM) is the standard tool for this question.

The Classic CLPM

In a two-wave, two-variable CLPM with variables S (financial stress) and B (risky borrowing):

\[S_{t+1} = a_{SS} \cdot S_t + a_{SB} \cdot B_t + \varepsilon_{S,t+1}\] \[B_{t+1} = a_{BB} \cdot B_t + a_{BS} \cdot S_t + \varepsilon_{B,t+1}\]

Four parameters: - \(a_{SS}\), \(a_{BB}\): autoregressive effects — stability of each variable over time - \(a_{SB}\): cross-lagged effect of B at time \(t\) on S at time \(t+1\) - \(a_{BS}\): cross-lagged effect of S at time \(t\) on B at time \(t+1\)

Code 
# Simulate 3-wave panel data
n <- 200
n_waves <- 3

# True DGP: financial stress -> risky borrowing (not the reverse)
S <- matrix(NA, n, n_waves)
B <- matrix(NA, n, n_waves)

S[, 1] <- rnorm(n, 50, 8)   # baseline financial stress
B[, 1] <- rnorm(n, 45, 7)   # baseline borrowing propensity

for (t in 2:n_waves) {
  S[, t] <- 0.6 * S[, t-1] + 0.1 * B[, t-1] + rnorm(n, 0, 5)  # small B->S effect
  B[, t] <- 0.6 * B[, t-1] + 0.3 * S[, t-1] + rnorm(n, 0, 5)  # strong S->B effect
}

df_clpm <- as.data.frame(cbind(S, B)) |>
  setNames(c(paste0("S", 1:3), paste0("B", 1:3)))
Code 
# Classic CLPM in lavaan
clpm_model <- '
  # Autoregressive effects
  S2 ~ a_SS * S1
  S3 ~ a_SS * S2
  B2 ~ a_BB * B1
  B3 ~ a_BB * B2

  # Cross-lagged effects
  S2 ~ a_SB * B1
  S3 ~ a_SB * B2
  B2 ~ a_BS * S1
  B3 ~ a_BS * S2

  # Residual covariances (within same wave)
  S2 ~~ B2
  S3 ~~ B3

  # Variance of wave 1
  S1 ~~ S1
  B1 ~~ B1
  S1 ~~ B1
'

m_clpm <- sem(clpm_model, data = df_clpm)
parameterEstimates(m_clpm) |>
  filter(op == "~") |>
  select(lhs, rhs, label, est, se, pvalue) |>
  knitr::kable(digits = 3,
    caption = "CLPM: cross-lagged path from S→B is strong; B→S is weak")

The Problem with Classic CLPM

The classic CLPM conflates within-person dynamics with between-person differences. Consider: people who are chronically financially stressed tend to also engage in chronically riskier borrowing (stable between-person correlation). The cross-lagged paths in the classic CLPM pick up both this stable between-person covariation and the genuine within-person dynamic — they cannot be separated.

This means even if there is no within-person causal relationship between financial stress and risky borrowing (i.e., changes in financial stress within a person do not cause changes in borrowing behavior), the classic CLPM can show significant “cross-lagged” effects simply because chronically stressed people also tend to borrow more riskily.

The Same Observed Pattern, Three Different Stories

The same observed correlations between financial stress and risky borrowing across waves are consistent with three completely different causal stories. The classic CLPM cannot distinguish them without extending the model.

All three stories produce the same bivariate correlation pattern between \(S_t\) and \(B_{t+1}\), and between \(B_t\) and \(S_{t+1}\). The classic CLPM cannot distinguish them because it does not separate stable between-person covariation (Story C) from genuine within-person dynamics (Stories A and B). The RI-CLPM separates these sources explicitly, making it the correct model for the within-person question.

The Random Intercept CLPM (RI-CLPM)

Hamaker, Kuiper, & Grasman (2015) proposed the Random Intercept CLPM, which solves this by separating two sources of variation:

  1. Between-person: Stable trait levels (random intercepts) that explain why some people are chronically higher on S or B
  2. Within-person: Fluctuations around each person’s stable level, and the cross-lagged dynamics among those fluctuations
Code 
ri_clpm_model <- '
  # Random intercepts (stable between-person levels)
  RI_S =~ 1*S1 + 1*S2 + 1*S3
  RI_B =~ 1*B1 + 1*B2 + 1*B3

  # Within-person components (deviations from stable level)
  wS1 =~ 1*S1; wS2 =~ 1*S2; wS3 =~ 1*S3
  wB1 =~ 1*B1; wB2 =~ 1*B2; wB3 =~ 1*B3

  # Constrain observed variances to 0 (all captured by RI + within)
  S1 ~~ 0*S1; S2 ~~ 0*S2; S3 ~~ 0*S3
  B1 ~~ 0*B1; B2 ~~ 0*B2; B3 ~~ 0*B3

  # Within-person cross-lagged dynamics
  wS2 ~ a_SS*wS1 + a_SB*wB1
  wS3 ~ a_SS*wS2 + a_SB*wB2
  wB2 ~ a_BB*wB1 + a_BS*wS1
  wB3 ~ a_BB*wB2 + a_BS*wS2

  # Random intercept variances and covariance
  RI_S ~~ RI_S; RI_B ~~ RI_B; RI_S ~~ RI_B

  # Within-person residual variances
  wS1 ~~ wS1; wB1 ~~ wB1
  wS2 ~~ wS2; wB2 ~~ wB2
  wS3 ~~ wS3; wB3 ~~ wB3
  wS2 ~~ wB2; wS3 ~~ wB3

  # Mean structure
  RI_S ~ 1; RI_B ~ 1
  wS1 ~ 0; wB1 ~ 0
'

m_ri_clpm <- sem(ri_clpm_model, data = df_clpm, estimator = "ML")

parameterEstimates(m_ri_clpm) |>
  filter(op == "~", lhs %in% c("wS2","wS3","wB2","wB3")) |>
  select(lhs, rhs, label, est, se, pvalue) |>
  knitr::kable(digits = 3,
    caption = "RI-CLPM: within-person cross-lagged effects (controls for stable between-person differences)")

Comparing CLPM vs. RI-CLPM

Feature Classic CLPM RI-CLPM
Controls for stable between-person differences? No Yes
Cross-lagged = within-person dynamics? No (confounded) Yes
More parameters? No Yes (random intercepts)
Better for causal within-person questions? No Yes
WarningAssumption: Stationarity of Cross-Lagged Effects

What it means: The CLPM (and RI-CLPM) typically constrains cross-lagged effects to be equal across waves. This assumes the dynamics do not change over the study period.

How to check: Fit an unconstrained model (different path coefficients at each wave) and compare fit to the constrained model.

WarningAssumption: No Omitted Dynamics

What it means: Both models assume all relevant variables are included. An omitted third variable that drives both S and B could produce spurious cross-lagged effects.

How to check: Think carefully about what else changes over time that could explain both variables. Include plausible third variables as additional nodes.

If this fails: Cross-lagged coefficients are observational associations, not causal estimates. Limit the interpretation to “S at time t predicts B at time t+1 above and beyond B’s own stability, while controlling for the variables in the model” — not “S causes B.”

Reviewer Challenge

TipWhat a Reviewer Would Ask

Challenge 1: “Your classic CLPM shows stress predicts borrowing — but isn’t it possible that chronically stressed people also tend to borrow more? How do you know this is a dynamic within-person effect rather than a stable between-person correlation?” The correct response: show the RI-CLPM results alongside the classic CLPM. If the RI-CLPM cross-lagged path is smaller or non-significant while the classic CLPM path is large, stable trait differences were driving the apparent dynamic effect. Report both models and interpret accordingly.

Challenge 2: “You constrain the cross-lagged paths to be equal across waves — but what if the stress-borrowing relationship changes over the study (e.g., as the economic environment changes)?” Fit the unconstrained model (free paths at each wave) and compare fit with a likelihood ratio test. If the unconstrained model fits significantly better, report the wave-varying paths and discuss what might explain the change.

Challenge 3: “You have only 3 waves — is that enough to reliably estimate cross-lagged dynamics?” Three waves is the minimum. With 3 waves, you estimate one set of cross-lagged paths (wave 1 → wave 2 and wave 2 → wave 3, constrained equal). This is adequate for a preliminary test but limited in power and unable to detect non-stationarity. More waves provide better estimates. Report this limitation explicitly.
